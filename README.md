# LPU CSE-AIML RAG Chatbot

A retrieval-augmented chatbot for LPU CSE-AIML academic information.

## Directory guide

- `backend/` — FastAPI application and backend tests.
- `frontend/` — React interface source, pages, services, and assets.
- `data/raw/` — source material, grouped by syllabus, regulations, notices, FAQs, and policies.
- `data/processed/` — derived data prepared for retrieval.
- `data/evaluation/` — evaluation datasets and results.
- `docs/` — requirements and project documentation.
- `scripts/` — maintenance and data preparation scripts.
